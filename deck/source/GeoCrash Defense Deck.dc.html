03 — Motivation & TaskGeoCrash DE

Four open datasets that don’t talk to each other

The problem

Germany publishes accident, population, vehicle-registration and administrative-boundary data as separate datasets — separate formats, separate update schedules, and region codes that get reorganized over time.

None of it is directly queryable together out of the box.

The task

Fuse them into one coherent, queryable, mappable whole — and do it so it can be regenerated from scratch on demand, not imported once by hand.

→≥ 3 official German open-data sources
→Documented REST API + visual frontend
→Answer 5 + 2 mandatory examiner questions

11 — Bonus Questionbonus category · zero cases

Municipalities with zero accidents in a year

The “zero cases” bonus asks for something the fact table alone can’t show: the regions where nothing happened.

The answer is the absence of rows — a CTE lists every region that spatially contains an accident that year (ST_Within), then NOT IN returns the regions that never appear. It tests that the region catalog is complete, not just the accident data.

→Only works because regions is a full catalog, independent of accidents
WITH accident_regions AS (
SELECT DISTINCT r.ags
FROM accidents a
JOIN regions r ON ST_Within(a.geom, r.geom)
WHERE r.level = :level AND a.year = :year
)
SELECT r.ags, r.name
FROM regions r
WHERE r.level = :level
AND r.ags NOT IN (SELECT ags FROM accident_regions)
ORDER BY r.name;

13 — Challengesproblem → solution

Two problems that shaped the build

Challenge 01
Region codes that shift under you

Problem — AGS codes carry meaningful leading zeros (“01001” ≠ 1001), and districts get merged & split over time (Kreisreform).

Solution — store ags as TEXT everywhere; resolve every raw code to its canonical 2024 form via regions_history, with a structural prefix rule for Hamburg & Berlin.

Challenge 02
You can’t draw 3 million points

Problem — rendering every accident at once is both too slow and visually meaningless — a black smear over the whole country.

Solution — show a different truth at every zoom, each fetching only the current viewport:

farchoropleth of district counts
midGPU-aggregated deck.gl hex bins
streetindividual canvas markers
